# Syntax Bridge
IDE de transpilação de C/C++ para Dart. A arquitetura deve permitir expansão de outras linguagens de entrada e saída.

### Aspectos técnicos
Ferramentas que serão usadas:
  - libclang
  - clang
  - clang++
  - cmake
  - dart sdk
  - klee
  - gunit

Ferramentas de empacotamento:
  - Linux: flatpak
